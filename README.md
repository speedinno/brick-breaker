# Brick Breaker public policies and support

Public website for Brick Breaker by SPEEDINNO PRIVATE LIMITED.

Contains only the support landing page, privacy notice, terms, account-deletion request instructions, shared stylesheet, third-party notices and a small retirement worker that removes the former web game’s offline caches. No game source, backend, SDK bundles, app binaries, build workflows or credentials are published here.

Website: https://speedinno.github.io/brick-breaker/

Account deletion requests: https://speedinno.github.io/brick-breaker/delete-account.html

Development and app builds are maintained separately in a private repository.
